# Facebook Archive Explorer v0.1.0-beta.2

This commit triggers the second public beta packaging workflow.

Changes since beta.1:
- Upgrade from end-of-life Electron 37 to supported Electron 45.4.1.
- Add a dedicated Groups workspace for the three reviewed Accounts Center Groups JSON collections.
- Keep unknown Groups schemas in Other Data rather than guessing their structure.
- Improve Groups and Other Data navigation so each view displays only its own sections.
- Include the Windows installer SHA-256 verification record with build artifacts and release assets.

The installer remains unsigned unless trusted Authenticode signing credentials are configured. Smart App Control may block unsigned binaries that Microsoft does not already recognize.

The stable v1.0.0 release remains gated by the full real-export end-to-end, large-archive, clean-Windows, and privacy/security checklist in docs/ROADMAP.md.
