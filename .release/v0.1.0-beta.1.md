# Facebook Archive Explorer v0.1.0-beta.1

This commit triggers the first public beta packaging workflow.

Release rules:
- This is an early-access pre-release, not the stable 1.0.0 release.
- The Windows installer is unsigned unless trusted Authenticode signing credentials are configured in repository Actions secrets.
- Smart App Control may block unsigned binaries that Microsoft does not already recognize.
- The release must pass Windows packaging verification, PowerShell syntax validation, TypeScript checks, and the unit test suite before publication.

The stable v1.0.0 release remains gated by the real-export end-to-end, large-archive, clean-Windows, and privacy/security checklist in docs/ROADMAP.md.
